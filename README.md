The funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

## The label

> WARNING: This human will say "I'm five minutes away" for the next forty minutes. Plan accordingly.

Every human alive has told someone they are "five minutes away" while still on the sofa. The joke is recognition, the turn lands in the last few words, and it reads like a real printed warning.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes the label to `/output/entry.txt` (98 characters, one line) and refuses to write anything outside the 1–160 character gate.
